# 📝 서예 코치 v2 - 서체 목록

## 🖌️ 한글 서체 (붓글씨)

### 1. 판본체 (panbon)
- **특징**: 조선 궁중의 정갈한 서체
- **코스**: brush-panbon (2개 레슨)
- **평가 기준**:
  - 정갈함과 균형 중시
  - 일정한 획 두께
  - 정사각형 틀 안의 균형
  - 단정한 마무리

### 2. 궁서체 (gungseo) 
- **특징**: 조선 궁중에서 사용된 아름다운 서체
- **코스**: brush-gungseo (11개 레슨)
- **평가 기준**:
  - 유연한 곡선미
  - 기필-송필-수필의 조화
  - 우아한 필압 변화
  - 자연스러운 연결

## ✏️ 한글 서체 (펜글씨)

### 3. K-Culture 스타일 (standard/modern)
- **특징**: 현대적이고 실용적인 한글
- **코스**: pen-hangul-kculture (12개 레슨)
- **평가 기준**:
  - 가독성과 명확성
  - 일관된 크기와 간격
  - 현대적 감각
  - 빠른 필기 가능

## 🈲 한자 서체 (계획 중)

### 4. 해서체 (haeseo) - 예정
- **특징**: 한문 서예의 기본 정자체
- **평가 기준**:
  - 획의 정확성
  - 구조의 안정성
  - 정방형 균형
  - 기본 필법 준수

### 5. 전서체 (jeonseo) - 예정  
- **특징**: 고대 인장에 사용된 서체
- **평가 기준**:
  - 장식적 요소
  - 대칭과 균형
  - 획의 균일성
  - 고전적 미감
