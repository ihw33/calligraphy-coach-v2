# 📚 서예 코치 v2 - 커리큘럼 구조 정리

## 🎯 학습 경로 체계

### 1️⃣ **한글 (Korean)**

#### 📝 펜글씨 (Pen Writing) - ✅ 있음
- **대상**: 미취학 아동, 외국인 학습자, 일반인
- **도구**: 연필, 볼펜, 사인펜
- **내용**:
  - 자음/모음 기초 학습
  - 단어 쓰기 연습
  - 문장 쓰기 연습
  - 일상 필기체
- **연습 방식**: 디지털 캔버스에 직접 쓰기
- **평가**: 정확도, 일관성, 깔끔함

#### 🎨 붓글씨 (Brush/Calligraphy) - ✅ 있음
- **대상**: 서예 학습자, 예술 관심자
- **도구**: 붓, 먹
- **내용**:
  - 판본체 (전통 인쇄체)
  - 궁서체 (궁중 서체)
- **연습 방식**: 실물 작성 → 사진 촬영/업로드
- **평가**: 형태, 비례, 필압, 획순

---

### 2️⃣ **한자 (Chinese Characters)**

#### 📝 펜글씨 (Pen Writing) - ✅ 있음
- **대상**: 한자능력시험 준비생, 학생
- **도구**: 연필, 펜
- **내용**:
  - 한자능력시험 급수별 (8급~1급)
  - 한자어 학습
  - 사자성어
- **연습 방식**: 디지털 캔버스에 직접 쓰기
- **평가**: 정확도, 획순, 구조

#### 🎨 붓글씨 (Brush/Calligraphy) - ✅ 있음
- **대상**: 서예 학습자, 전통 예술 관심자
- **도구**: 붓, 먹
- **내용**:
  - 해서체 (楷書)
  - 행서체 (行書)
  - 전서체 (篆書)
  - 예서체 (隸書)
  - 초서체 (草書)
  - 해서 결구 92법
  - 임서 (작가별 따라쓰기)
- **연습 방식**: 실물 작성 → 사진 촬영/업로드
- **평가**: 형태, 비례, 필압, 획순, 전통미

## 🔄 학습 모드 구분

### 디지털 모드 (Canvas)
- **적용**: 펜글씨 (한글/한자)
- **특징**: 
  - 실시간 획 인식
  - 즉각적인 피드백
  - 디지털 펜/마우스 사용
  - 압력 감지 지원

### 실물 모드 (Photo)
- **적용**: 붓글씨 (한글/한자)
- **특징**:
  - 종이에 실제 붓으로 작성
  - 카메라 촬영 또는 이미지 업로드
  - AI 비전 평가
  - 전통 서예 기법 평가
