# 🎯 서예 코치 v2 - 메뉴 구조 제안

## 핵심 정체성
- **메인**: 전통 서예 (붓글씨) 교육
- **서브**: 외국인 한글 학습 / 한자능력시험 대비
- **최종 목표**: 모든 사용자를 서예로 유도

## 🎨 UI/UX 전략

### 1. 진입점 차별화
```
[한글 배우기]          [서예 마스터]          [한자 공부]
  "쉽고 재밌게"        "전통의 아름다움"       "시험 준비"
   → K-Culture         → 붓글씨 중심          → 능력시험
   → 서예 유도         → 핵심 콘텐츠         → 서예 유도
```

### 2. 자연스러운 유도 플로우

#### K-Culture 완료 시:
```
"축하합니다! 🎉"
"이제 진짜 한국 전통 서예를 배워보시겠어요?"
[판본체 시작하기] [나중에]
```

#### 한자능력시험 학습 중:
```
"💡 Tip: 한자를 더 아름답게 쓰고 싶으신가요?"
"서예 마스터들의 작품으로 배우면 실력이 2배!"
[왕희지 천자문 보기]
```

### 3. 메뉴 레이블링 전략

#### 현재 사용자용
- "서예" → 한국인이 바로 이해
- "법첩" → 서예 학습자가 아는 용어

#### 신규 사용자용  
- "한글 배우기" → 외국인 친화적
- "한자 공부" → 시험 준비생 친화적
- "Learn Korean" → 영어 병기

## 📊 추천 구현 순서

### Phase 1: 메뉴 재구조화
1. 현재 CourseSelection 컴포넌트 수정
2. 3개 메인 카테고리 분리
3. 서예를 중앙에 배치 (시각적 강조)

### Phase 2: 유도 시스템
1. 코스 완료 시 서예 추천 팝업
2. 진도 50% 시점에 "다음 단계" 제안
3. 홈 화면에 "오늘의 서예" 위젯

### Phase 3: 통합 대시보드
1. 전체 학습 경로 시각화
2. 한글 → 서예 연결선
3. 한자 → 서예 연결선

## 🎯 최종 목표 달성 전략

### 단계별 전환
1. **진입**: K-Culture / 한자시험 (쉬운 시작)
2. **관심**: 서예 맛보기 (체험 레슨)
3. **몰입**: 본격 서예 (판본체/왕희지)
4. **마스터**: 전체 법첩 (전문가 과정)

### 동기 부여 시스템
- 🏆 "K-Culture 마스터" → "판본체 입문자" 배지
- 🎖️ "한자 8급" → "왕희지 제자" 배지
- 📜 인증서: "전통 서예 ○○체 수료"
