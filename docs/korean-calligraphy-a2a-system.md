# 한글 서예 A2A 학습 시스템

## 🎯 시스템 개요

K-Culture와 실용 한글을 결합한 서예 학습 시스템
- **목표**: 외국인과 한국인 모두를 위한 재미있는 한글 서예 학습
- **특징**: 기초부터 K-POP까지 단계별 학습
- **방법**: 5개 AI Agent가 협업하여 맞춤형 교육 제공

---

## 👥 A2A Agent 구성

### Agent 1: 기초 마스터 (Basic Master)
**담당**: 자음 10개 + 모음 6개 + 기본 글자 조합

#### 1단계: 자음/모음 (1주차)
```
기본 자음: ㄱ ㄴ ㄷ ㄹ ㅁ ㅂ ㅅ ㅇ ㅈ ㅎ
기본 모음: ㅏ ㅓ ㅗ ㅜ ㅡ ㅣ
복합 모음: ㅑ ㅕ ㅛ ㅠ ㅐ ㅔ ㅒ ㅖ
```

#### 2단계: 기본 조합 글자 (2주차)
```
가족: 가 나 다 라 마 바 사 아 자 차 카 타 파 하
거족: 거 너 더 러 머 버 서 어 저 처 커 터 퍼 허
고족: 고 노 도 로 모 보 소 오 조 초 코 토 포 호
구족: 구 누 두 루 무 부 수 우 주 추 쿠 투 푸 후
그족: 그 느 드 르 므 브 스 으 즈 츠 크 트 프 흐
기족: 기 니 디 리 미 비 시 이 지 치 키 티 피 히
```

#### 3단계: 받침 있는 글자 (3주차)
```
단자음 받침: 각 간 날 달 람 밤 산 안 잘 찬 칸 탄 판 한
쌍자음 받침: 갔 났 닫 랐 맛 밧 삿 았 짧 찼 캤 탔 팠 했
복합 받침: 갉 긁 낡 닭 맑 밝 삶 앉 잦 찮 칡 탉 팥 핥
```

#### 4단계: 일상 필수 글자 (4주차)
```
인사말: 안녕 하세요 감사 합니다 미안 죄송
가족: 엄마 아빠 형 누나 언니 오빠 동생
시간: 오늘 내일 어제 지금 아침 점심 저녁
장소: 학교 집 회사 병원 가게 시장 공원
```

**책임**:
- 획순 애니메이션 생성 (자음/모음/조합 각각)
- 기본 붓 잡기 및 압력 가이드
- 글자 구조 분해 설명 (초성+중성+종성)
- 10분 속성 코스 제공
- 판본체 기준 모범 답안 제시

**학습 방법**:
1. **자모음 분해 학습**: 가 = ㄱ + ㅏ
2. **획순 단계별**: ① 초성 → ② 중성 → ③ 종성
3. **압력 포인트**: 시작점(강) → 중간(중) → 끝점(약)
4. **공간 배분**: 3:4:3 비율 (초성:중성:종성)

**평가 기준**:
- ✅ 획순 정확도 (Pass/Fail)
- ✅ 기본 형태 인식 (60% 이상)
- ✅ 자모 균형 (초성/중성/종성 비율)
- ✅ 완성 시간 (각 글자 30초 이내)
- ✅ 압력 변화 (농담 표현)

**난이도 진행**:
```
Level 1: ㄱ, ㅏ → 가 (5분)
Level 2: 가나다라 (10분)
Level 3: 간단한 받침 (각, 간) (15분)
Level 4: 복잡한 받침 (닭, 삶) (20분)
Level 5: 완성 단어 (안녕하세요) (25분)
```

### Agent 2: 일상 단어 전문가 (Daily Words Expert)
**담당**: 품사별 필수 단어

**명사 카테고리**:
```
일상: 사람, 친구, 가족, 학교, 회사
음식: 음식, 커피, 치킨, 피자, 김밥
기기: 핸드폰, 컴퓨터, 지하철, 버스
```

**동사 카테고리**:
```
기본: 가다, 오다, 먹다, 자다, 하다
감각: 보다, 듣다, 말하다, 사랑하다
활동: 공부하다, 일하다, 놀다
```

**형용사/부사**:
```
형용사: 좋다, 예쁘다, 맛있다, 재미있다, 크다, 작다
부사: 매우, 정말, 너무, 빨리, 천천히, 오늘, 내일
```

**교육 방법**:
- 단어별 서예 템플릿 제공
- 실생활 문장 만들기 연습
- 자주 쓰는 조합 패턴 학습

### Agent 3: K-Culture 트렌드 큐레이터 (K-Culture Curator)
**담당**: K-POP, 드라마, 음식, 유행어

**K-POP 아티스트** 🎵:
```
글로벌: 방탄소년단, 블랙핑크, 세븐틴
4세대: 뉴진스, 아이브, 에스파
솔로: 아이유, 임영웅
```

**인기 드라마** 📺:
```
글로벌 히트: 오징어게임, 이태원클라쓰
로맨스: 사랑의불시착
사극/스릴러: 킹덤, 더글로리, 재벌집막내아들
```

**한국 음식** 🍜:
```
전통: 불고기, 비빔밥, 김치찌개, 된장찌개
인기: 떡볶이, 삼겹살
트렌드: 치맥, 소주
```

**유행어/인터넷 용어** 💬:
```
감탄사: 대박, 짱, 헐, 굿
응원: 화이팅, 파이팅
이모티콘: ㅋㅋㅋ, ㅎㅎㅎ, ㅠㅠ
```

**저작권 안전 가이드**:
- ✅ 사용 가능: 아티스트명, 드라마 제목, 음식명, 일반 유행어
- ❌ 사용 불가: 로고, 가사, 대사, 캐릭터 이미지

### Agent 4: 서예 평가 마스터 (Calligraphy Evaluator)
**담당**: 실시간 평가 및 피드백

**평가 항목**:
```python
class CalligraphyEvaluation:
    def __init__(self):
        self.criteria = {
            "형태_정확도": 40,  # 글자 모양
            "획순_준수": 20,    # 순서 정확성
            "균형_미감": 20,    # 전체 균형
            "붓_압력": 20       # 농담 표현
        }
```

**레벨 시스템**:
1. 🌱 새싹 (Beginner): 자음/모음 완성
2. 🌿 잎새 (Elementary): 단어 10개 완성
3. 🌳 나무 (Intermediate): 문장 쓰기 가능
4. 🌸 꽃 (Advanced): K-Culture 단어 마스터
5. 🏆 명인 (Master): 창작 서예 가능

**피드백 방식**:
- 실시간 붓 궤적 분석
- AI 시각화 피드백
- 개선점 하이라이트
- 모범 답안 오버레이

### Agent 5: 학습 진도 매니저 (Progress Manager)
**담당**: 개인 맞춤 커리큘럼

**학습 경로 설계**:
```
1주차: 기초 자음/모음 (Agent 1)
  ↓
2주차: 일상 단어 20개 (Agent 2)
  ↓
3주차: 짧은 문장 5개 (Agent 2)
  ↓
4주차: K-POP 아티스트명 (Agent 3)
  ↓
5주차: 좋아하는 드라마 제목 (Agent 3)
  ↓
6주차: 창작 문구 만들기 (All Agents)
```

**동기부여 시스템**:
- 🏅 일일 미션 (3개 글자 완성)
- 🎁 주간 챌린지 (좋아하는 가수 이름 쓰기)
- 📊 진도 시각화 대시보드
- 🎨 작품 갤러리 공유
