# 🎯 Figma 플러그인 대안 방법

## 방법 1: Figma Dev Mode 사용 (추천)

1. **Dev Mode 활성화**
   - 우측 상단 토글: Design ↔️ Dev
   - Dev Mode로 전환

2. **코드 확인**
   - 버튼 선택
   - 우측 패널에서 코드 스니펫 확인
   - CSS, iOS, Android 코드 제공

## 방법 2: Figma Tokens 플러그인

1. **Figma Tokens 검색**
   - 디자인 토큰 관리 플러그인
   - 색상, 스페이싱 등 추출 가능

## 방법 3: 수동으로 속성 복사

1. **버튼 선택**
2. **우측 패널에서 확인**:
   - Width: 120
   - Height: 48  
   - Fill: #4F46E5
   - Corner Radius: 8
   - Text: "시작하기"

3. **이 정보를 저에게 알려주세요**:
   ```
   버튼 속성:
   - 크기: 120x48
   - 색상: #4F46E5
   - 모서리: 8px
   - 텍스트: 시작하기
   - 폰트: [폰트명]
   - 폰트 크기: [크기]
   ```
