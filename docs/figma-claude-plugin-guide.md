# Figma Claude 플러그인 설치 및 연결 가이드

## 1️⃣ Figma 플러그인 설치

1. **Figma 열기**
   - Figma 데스크톱 앱 또는 웹 브라우저에서 Figma 열기
   - 디자인 파일 열기

2. **플러그인 메뉴 접속**
   - 상단 메뉴: Resources → Plugins
   - 또는 단축키: Mac (⌥⌘P) / Windows (Alt+Ctrl+P)

3. **Claude 플러그인 검색**
   - "Claude" 또는 "Claude Talk to Figma" 검색
   - 플러그인이 없다면 Community 탭에서 검색

4. **플러그인 설치**
   - "Run" 또는 "Install" 클릭
   - 권한 승인

## 2️⃣ 플러그인 실행 및 연결

1. **플러그인 실행**
   - Plugins → Claude Talk to Figma → Run
   - 플러그인 창이 열립니다

2. **채널 생성/연결**
   - 플러그인에서 채널 이름 확인
   - 예: "figma-abc123" 같은 형식

3. **Claude에서 연결**
   - Claude에게 채널 이름 알려주기
   - "Figma 채널 'figma-abc123'에 연결해줘"
