# 🎨 Figma-GitHub 연동 사용 가이드

## 1️⃣ Figma Access Token 발급하기

1. **Figma 계정 설정 페이지 접속**
   - https://www.figma.com/settings 로 이동
   - 로그인이 안 되어있다면 로그인

2. **Personal Access Tokens 섹션 찾기**
   - 페이지 아래쪽으로 스크롤
   - "Personal Access Tokens" 섹션 확인

3. **새 토큰 생성**
   - "Create new token" 버튼 클릭
   - 토큰 이름 입력 (예: "Calligraphy Coach Sync")
   - "Create token" 클릭

4. **토큰 복사 및 저장**
   - 생성된 토큰 복사 (figd_로 시작하는 문자열)
   - ⚠️ 중요: 이 토큰은 다시 볼 수 없으므로 안전한 곳에 저장!

![Figma Token 생성 예시]
```
figd_1234567890abcdefghijklmnopqrstuvwxyz
```
