# Practice (Camera/Canvas) Blueprint

- Purpose: Capture or draw strokes aligned to reference
- Primary Actions: Capture, Draw, Undo, Clear, Next(Evaluate)
- Layout: Reference overlay / Canvas area / Controls bar
- Components: Canvas, Button, Slider, Switch, Card (tooltips optional)
- States: Camera active, Canvas drawing, Error(no permission)
- A11y: Buttons labeled, slider name, back action
- Metrics: Time-to-first-stroke, control error rate
