# 화면 구성 가이드 (MVP)

## 공통 레이아웃
- 상단: 최소 헤더(뒤로가기/설정)
- 본문: 콘텐츠 영역(그리드 12, 모바일 4)
- 하단: 주요 액션(촬영/평가/저장)

## 간격 및 그리드
- 기본 간격: var(--space-4) = 16px
- 섹션 간격: var(--space-6) = 24px
- 코너 반경: var(--radius-md) = 12px

## 타이포그래피
- 본문: var(--text-md)
- 캡션/보조: var(--text-sm|xs)
- 제목: var(--text-xl)

## 상호작용
- 버튼 프라이머리: var(--color-primary)
- 피드백 색: 긍정 var(--color-accent), 경고 #f59e0b, 오류 #ef4444

## 접근성
- 대비비 4.5:1 이상 유지
- 포커스 링 명확 표시(키보드 네비게이션)
