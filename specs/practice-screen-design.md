# PracticeScreen 페이지 설계 문서

## 1. 페이지 개요
**목적**: 서예 연습을 위한 통합 학습 페이지
**위치**: `/practice` 또는 `/practice/:sessionId`
**모드**: 디지털(Canvas) / 실물(Camera)

## 2. 페이지 구조

### 2.1 헤더 영역
```
[뒤로가기] ━━━━━━ 진행바 (3/5) ━━━━━━ [코스명]
```
- **좌측**: 뒤로가기 버튼 (둥근 배경)
- **중앙**: 진행 상태바 + 현재/전체 표시
- **우측**: 코스 제목 (예: "황자원 92 서법", "판본체 기초")

### 2.2 메인 콘텐츠

## 3. 데이터 흐름

### 3.1 진입 경로
1. **코스 선택**: `/course/:courseId` → 레슨 클릭
2. **빠른 시작**: `/practice/quick-start`
3. **이어하기**: `/practice/continue`

### 3.2 location.state 구조
```typescript
{
  courseId: string;         // 코스 ID
  lessonId: string;         // 레슨 ID
  characters: Character[];  // 연습할 문자 배열
  mode: 'canvas' | 'photo'; // 기본 모드
  fontStyle?: string;       // 서체 (해서, 궁서 등)
  lessonTitle?: string;     // 레슨 제목
  evaluationPoints?: string[]; // 평가 포인트 (황92)
}
```

### 3.3 Character 타입
```typescript
interface Character {
  id: string;
  character: string;      // 실제 문자
  type: 'korean' | 'chinese';
  meaning?: string;       // 한자 뜻
  pronunciation?: string; // 한자 음
  referenceImage?: string;
}
```

## 4. 평가 시스템

### 4.1 실물 모드 평가 (황자원 92 서법 전용)
1. 카메라 촬영 또는 이미지 업로드
2. Base64 인코딩
3. LLM API 호출 (evaluatePhotoMode)
4. 서법별 평가 기준 적용
5. 결과: 형태(35) + 비례(35) + 필압(15) + 획순(15)

### 4.2 평가 결과 표시
- 즉시 피드백: 점수 표시
- 상세 피드백: ResultScreen으로 이동
- 저장: IndexedDB + 서버 동기화

## 5. 특수 기능

### 5.1 황자원 92 서법
- 서법별 평가 포인트 표시
- 4개 한자씩 레슨 구성
- 해서체 기본 설정
- 서법 원리 중심 평가

### 5.2 한글 판본체
- 자모 분해 가이드
- 획순 오버레이
- 초성/중성/종성 표시

### 5.3 진도 관리
- 자동 저장
- 다음 문자 이동
- 레슨 완료 처리

### 6.1 젠 스타일
- 미니멀 디자인
- 둥근 모서리 (rounded-lg)

### 6.2 반응형

## 7. 에러 처리

### 7.1 카메라 권한
- 권한 요청 프롬프트
- 거부 시 업로드 옵션 제공

### 7.2 평가 실패
- 재시도 버튼
- 폴백 평가 자동 실행
- 에러 메시지 표시

### 7.3 네트워크
- 오프라인 모드 지원
- 로컬 저장 후 동기화

## 8. 성능 목표
- Canvas: 60fps 유지
- 카메라: 1920x1080 해상도
- 평가 응답: <3초
- 메모리: <100MB
