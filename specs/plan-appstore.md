# 📱 서예 코치 v2 - 앱스토어 등록 계획

## 🎯 목표
- iOS/Android 앱스토어 동시 등록
- 홍보 채널 확보 및 사용자 접근성 향상
- 네이티브 기능 활용한 최적 UX 제공

## 🏗️ 기술 스택 결정

### 선택: React Native + Expo
**이유:**
- 현재 React 코드 최대한 재활용
- iOS/Android 동시 개발
- Expo를 통한 빠른 개발 및 배포
- 네이티브 모듈 접근 가능

### 대안 검토:
- ~~Capacitor/Ionic~~: 성능 이슈
- ~~Flutter~~: React 코드 재사용 불가
- ~~Native 각각~~: 개발 비용 과다

## 📊 개발 단계

### Phase 1: 기반 구축 (1주)
- React Native + Expo 프로젝트 초기화
- 현재 컴포넌트 → RN 컴포넌트 매핑 계획
- 네비게이션 시스템 구축 (React Navigation)
- 다국어 시스템 설정 (i18n)

### Phase 2: 핵심 기능 이식 (2주)
- Canvas → React Native Skia
- 인증 시스템 (구글/애플 로그인)
- 로컬 스토리지 → AsyncStorage
- 카메라 기능 (Expo Camera)

### Phase 3: UI/UX 최적화 (1주)
- 네이티브 제스처 구현
- 플랫폼별 UI 조정
- 성능 최적화
- 오프라인 모드

### Phase 4: 스토어 준비 (1주)
- 앱 아이콘/스플래시 스크린
- 스토어 스크린샷 (각 언어별)
- 앱 설명 작성 (ASO 최적화)
- 심사 준비

## 🌍 다국어 전략

1. **한국어** - 메인
