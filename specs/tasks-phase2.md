# Tasks: 2단계 - 실제 입력 및 평가 시스템

**Input**: 1단계 MVP 완료 (mvp.html 동작 확인됨)
**전략**: Lean TDD - Canvas/Camera 입력 → 이미지 비교 평가 → 표준 작품 기반

## 🎯 2단계 목표 
- **핵심 가치**: 실제 그리기/촬영 → 진짜 이미지 비교 평가 → 의미있는 점수
- **입력 방식**: Canvas API (직접 그리기) + Camera API (사진 촬영)
- **평가 방식**: 2D 마스크 비교 (면적, 중심점, 겹침 비율)
- **콘텐츠**: 표준 작품 기반 평가 시스템

## 🚫 3단계 이후 기능들 
- 복잡한 AI/ML 모델
- 획순 실시간 분석
- 서버 동기화
- 소셜 기능

---

## Phase 1: 실제 입력 시스템 (4)

- [ ] **T201** Canvas 그리기 구현 `mvp.html 업그레이드`
  - **작업 내용**: 더미 캔버스를 실제 HTML5 Canvas로 교체, 마우스/터치 이벤트 처리
  - **성공 기준**: 마우스로 그리기 가능, 지우기 버튼 동작, 선 굵기/색상 설정
  - **예상 시간**: 2시간

- [ ] **T202** Camera 촬영 구현 `mvp.html에 카메라 모드 추가`
  - **작업 내용**: getUserMedia API로 카메라 접근, 사진 촬영, 이미지 캡처
  - **성공 기준**: 카메라 화면 표시, 촬영 버튼으로 이미지 캡처, 결과 미리보기
  - **예상 시간**: 3시간

- [ ] **T203** 이미지 전처리 유틸 `공통 이미지 처리 함수`
  - **작업 내용**: Canvas/Camera 입력을 동일한 포맷으로 변환 (크기 조정, 흑백 변환)
  - **성공 기준**: 300x300 흑백 이미지로 정규화, 노이즈 제거
  - **예상 시간**: 2시간

- [ ] **T204** 입력 모드 선택 UI `Canvas/Camera 모드 전환`
  - **작업 내용**: 연습 화면에 "직접 그리기" / "사진 촬영" 모드 선택 버튼
  - **성공 기준**: 모드 전환 버튼, 각 모드별 UI 표시, 동일한 완료 플로우
  - **예상 시간**: 1시간

## Phase 2: 이미지 비교 평가 알고리즘 (3)

- [ ] **T205** 2D 마스크 생성 `이미지 → 마스크 변환`
  - **작업 내용**: 이미지를 64x64 그리드로 변환, 픽셀 밝기 기반 마스크 생성
  - **성공 기준**: 이미지 → Boolean[][] 마스크 변환, 임계값 설정
  - **예상 시간**: 2시간

- [ ] **T206** 마스크 비교 평가 함수 `면적/중심/겹침 비율 계산`
  - **작업 내용**: `evaluateMask(reference, user)` 구현, 4가지 요소별 점수 계산
  - **성공 기준**: 형태(40%), 비례(30%), 굵기(20%), 획순(10%) → 0-100점
  - **예상 시간**: 3시간

- [ ] **T207** 표준 작품 데이터 `참고 이미지 준비`
  - **작업 내용**: 30개 글자별 표준 이미지 수집/생성, 마스크 데이터 미리 계산
  - **성공 기준**: 각 글자별 참고 이미지 및 마스크 데이터 준비
  - **예상 시간**: 3시간

## Phase 3: 통합 및 개선 (3)

- [ ] **T208** 실제 평가 시스템 연결 `랜덤 점수 → 실제 평가`
  - **작업 내용**: mvp.html의 임시 점수를 실제 이미지 비교 결과로 교체
  - **성공 기준**: Canvas/Camera 입력 → 마스크 비교 → 실제 점수 표시
  - **예상 시간**: 2시간

- [ ] **T209** 점수 세부 정보 표시 `요소별 점수 및 피드백`
  - **작업 내용**: 결과 화면에 형태/비례/굵기/획순별 세부 점수 표시
  - **성공 기준**: 총점 + 4가지 세부 점수, 각 요소별 개선 제안
  - **예상 시간**: 2시간

- [ ] **T210** 성능 최적화 및 테스트 `실제 사용성 검증`
  - **작업 내용**: 이미지 처리 속도 최적화, 다양한 입력 테스트
  - **성공 기준**: 평가 시간 <2초, 다양한 글자/입력 방식 안정적 동작
  - **예상 시간**: 2시간
