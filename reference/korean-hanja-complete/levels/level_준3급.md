# 준3급 한자 (500자)

## 개요
- 총 500자 (준3급-1001번 ~ 준3급-1500번)
- 전국한자능력검정시험 준3급 배정한자
- 출처: 한국어문회
- 난이도: 중급 (4급 이상의 한자 500자 추가)
