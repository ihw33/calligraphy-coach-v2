## 학습 가이드

### 2단계: 기본기 확립 (6급→5급)
**기간**: 6-12개월  
**목표**: 한자 조합 이해와 어휘력 확장

#### 학습 순서
1. **동작 동사** (1-4주차)
   - 기본 동작: 行走立坐
   - 손 동작: 書讀作做
   - 감각 동작: 見聞言語

2. **상태 형용사** (5-8주차)
   - 크기: 大小長短高低
   - 색깔: 白黑紅青黃
   - 감정: 好惡喜怒哀樂

3. **시간 개념** (9-12주차)
   - 시간 단위: 時分秒刻
   - 하루 시간: 朝晝夕夜
   - 시기 표현: 早晩今古新舊

4. **장소와 공간** (13-16주차)
   - 자연 지형: 海江湖島
   - 건물과 시설: 家門窓室
   - 교통과 이동: 道路車馬

5. **인간 활동** (17-20주차)
   - 학습 활동: 學校先生
   - 생활 활동: 衣食住行
   - 사회 활동: 友朋社會

#### 연계성 특징
- **단어 조합 중심**: 2-3자 조합으로 의미 확장
- **문법적 기능**: 품사별 역할 이해
- **실용적 활용**: 일상 대화와 문서에서 활용 가능

#### 학습법 권장사항
- 단어장 만들기와 체계적 정리
- 예문 만들기와 문장 완성 연습
- 받아쓰기를 통한 정확성 확보
- 교과서 어휘와 연계 학습

### 형성자 패턴 학습

#### 청(青) 계열 한자
**공통 성음부**: 青 (푸를 청)
- **淸** (맑을 청): 물(氵) + 青 → 맑은 물
- **情** (감정 정): 마음(忄) + 青 → 마음의 상태
- **請** (청할 청): 말씀(訁) + 青 → 정중히 요청
- **晴** (맑을 청): 날씨(日) + 青 → 맑은 날씨

#### 학습 진도 관리

**중급 급수 (5급-4급)**
- **학습 목표**: 실용 어휘 확장
- **일일 학습량**: 10-15자
- **복습 주기**: 격일
- **평가 방법**: 단어 조합, 의미 설명
