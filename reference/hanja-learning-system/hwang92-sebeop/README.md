# 황자원 92서법 (Hwang Ja-won's 92 Calligraphy Methods)

## 📚 Overview

This directory contains materials related to 황자원(黃自元, 1837-1918)'s "간가결구 적요 구십이법" (間架結構摘要九十二法), a systematic guide to Chinese character structure and calligraphy.

## 🎯 92 Methods Categories

The 92 methods are organized into several key categories:

### 1. 기본 구조 (Basic Structure)
- 천복지재 (天覆地載) - Heaven covers, earth supports
- 좌우균형 (左右均衡) - Left-right balance
- 상하대칭 (上下對稱) - Top-bottom symmetry

### 2. 획의 관계 (Stroke Relationships)
- 점획 배치 (點畫配置) - Dot and stroke placement
- 획의 장단 (畫之長短) - Stroke length variations
- 획의 조밀 (畫之疏密) - Stroke density

### 3. 공간 활용 (Space Utilization)
- 내부 공간 (內部空間) - Internal spacing
- 외부 여백 (外部餘白) - External margins
- 전체 균형 (全體均衡) - Overall balance

## 🔍 Key Principles

1. **구조적 균형** - Structural balance is fundamental
2. **비례의 조화** - Harmonious proportions
3. **동적 안정** - Dynamic stability
4. **공간의 리듬** - Rhythmic spacing

## 📖 Usage Guide

1. Start with understanding basic structural principles
2. Study each method with its examples
3. Practice writing characters following these methods
4. Compare your work with the standard forms
