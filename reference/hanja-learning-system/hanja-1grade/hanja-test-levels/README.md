# 한자능력시험 급수별 자료 (Hanja Proficiency Test Materials)

## 📚 Overview

This directory contains comprehensive materials for the Korean Hanja Proficiency Test (한자능력시험), organized by levels from 8급 (beginner) to 특급 (special/highest).

## 📖 File Format

Each level file contains:
- **Character**: The Hanja character
- **Korean**: Korean pronunciation (음)
- **Meaning**: Korean meaning (훈)
- **Radical**: Character radical (부수)
- **Stroke Count**: Number of strokes
- **Common Words**: Example vocabulary
- **Grade Level**: Educational grade reference

## 🎯 Study Approach

### For Beginners (8급-5급)
1. Focus on basic character recognition
2. Learn stroke order and structure
3. Master common pronunciations
4. Build vocabulary with simple compounds

### For Intermediate (4급-3급)
1. Expand character knowledge systematically
2. Study character formation principles
3. Learn multiple readings per character
4. Practice reading comprehension

### For Advanced (준2급-특급)
1. Master complex character combinations
2. Understand classical Chinese texts
3. Study specialized vocabulary
4. Develop speed and accuracy

## 🎓 Test Preparation Tips

1. **Regular Practice**: Study characters daily, even if just 10-15 minutes
2. **Write by Hand**: Physical writing improves retention
3. **Use Context**: Learn characters within meaningful sentences
4. **Review Systematically**: Regular review of previously learned characters
5. **Test Yourself**: Use practice tests to identify weak areas
