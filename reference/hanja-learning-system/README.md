# Hanja Learning System - 한자 학습 시스템

## 📁 Directory Structure

This repository contains organized materials for Hanja (Chinese characters) learning, including:

- **hwang92-sebeop/** - 황자원 92서법 (Hwang Ja-won's 92 Calligraphy Methods)
- **hanja-test-levels/** - 한자능력시험 급수별 자료 (Hanja Proficiency Test Materials by Level)
- **sebeop-matching/** - 서법 매칭 알고리즘 (Calligraphy Method Matching Algorithms)
- **images/** - 관련 이미지 자료 (Related Images)
- **scripts/** - Python 스크립트 (Python Scripts)

---

## 📚 Contents Overview

### 1. 황자원 92서법 (hwang92-sebeop/)
- 황자원_서법_92법_완전판.md - Complete guide to 92 calligraphy methods
- complete_92_sebeop_table.md - Comprehensive table of all 92 methods
- Images of calligraphy examples

### 2. 한자능력시험 (hanja-test-levels/)
- Level files from 8급 to 특급
- Learning guides and study materials
- Complete character lists by level

### 3. 서법 매칭 시스템 (sebeop-matching/)
- Matching algorithms and analysis tools
- JSON data files with matching results
- Python scripts for analysis

### 4. 이미지 자료 (images/)
- Calligraphy examples
- Character stroke orders
- Visual learning materials

### 5. 스크립트 (scripts/)
- a2a_hanja_system.py - Main system script
- hanzi_sebeop_matching_a2a.py - Matching algorithm
- agent2_sebeop_analysis.py - Analysis tools
- agent3_matching_algorithm.py - Advanced matching

---

## 🚀 Getting Started

1. Navigate to the specific folder for your area of interest
2. Each subfolder contains its own README with detailed information
3. Python scripts can be run from the scripts/ directory
