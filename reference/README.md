## 🏛️ wangxizhi/ - 왕희지 집자성교서

### 개요
- **왕희지 집자성교서** (王羲之 集字聖敎序)
- 당나라 672년경 집자
- 행서체(行書體) 명품

### 주요 파일
- `wangxizhi-hanja-study.md` - 학습 가이드 (이미지 포함)
- `wangxizhi-hanja-data.json` - 한자 데이터베이스
- `wangxizhi-viewer.html` - 인터랙티브 뷰어
- `wangxizhi-images/images/` - 11개 한자 이미지
  - 大唐三藏聖敎序太宗文皇 (11자)

### 수록 한자
1. 大(대) - 큰
2. 唐(당) - 당나라
3. 三(삼) - 셋
4. 藏(장) - 감출
5. 聖(성) - 성인
6. 敎(교) - 가르칠
7. 序(서) - 차례
8. 太(태) - 클
9. 宗(종) - 마루
10. 文(문) - 글월
11. 皇(황) - 임금

## 📖 hanja-learning-system/ - 한자 학습 시스템

### 개요
체계적인 한자 학습을 위한 통합 시스템. 황자원 92서법, 한자능력검정시험 급수, 서예 매칭 알고리즘 등을 포함합니다.

### 하위 디렉토리

#### hwang92-sebeop/ - 황자원 92서법
- **황자원(黃自元, 1837-1918)** 간가결구 적요 구십이법
- 한자 구조의 92가지 원칙
- 서예 학습의 기본 이론

#### sebeop-matching/ - 서법 매칭 시스템
- 한자별 적합한 서법 추천
- 구조 분석 알고리즘
- 매칭 결과 데이터베이스

#### hanja-test-levels/ - 한자능력검정시험 급수
- 8급부터 특급까지 전 급수 자료
- 급수별 필수 한자 목록
- 학습 가이드

## 🎨 hwang92-sebeop/ - 황자원 92서법

### 주요 파일 ✅
- `황자원_서법_92법_완전판.md` - 92법 완전 설명서
- `complete_92_sebeop_table.md` - 92법 테이블

3. **상하대칭** (上下對稱) - 상하의 대칭
4. **점획배치** (點畫配置) - 점과 획의 배치
5. **공간활용** (空間活用) - 공간의 활용
