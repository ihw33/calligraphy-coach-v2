### 1. 천복자(天覆者) - 하늘이 덮는 자
**원문**: "天覆者凡畫皆冒於其下"  
**설명**: 위에 보개(宀)가 있는 글자는 나머지 획들이 모두 그 아래에 모여야 한다

**예시 글자**: 宇, 宙, 定

```
    宀    (보개두가 위를 덮음)
   ─┬─   
    │    (아래 획들이 보개 아래 집중)
    
실제 예시:
    宀     宀     宀
   ─宇─   ─宙─   ─定─
  (우)   (주)   (정)
```

---

### 2. 지재자(地載者) - 땅이 받치는 자
**원문**: "地載者有畫皆托於其上"  
**설명**: 아래에 받침이 있는 글자는 나머지 획들이 모두 그 위에 받쳐져야 한다

**예시 글자**: 至, 孟, 聖

```
   至孟聖  (위쪽 획들이 받쳐짐)
   ─┴─
  ━━━━━  (아래 받침이 전체를 떠받침)
  
실제 구조:
   ┌─至─┐
   └─────┘  (至자의 바닥이 넓게 받침)
   
   ┌─孟─┐
   └─────┘  (孟자의 기반이 안정)
```

---

### 3. 양좌자(讓左者) - 왼쪽에 양보하는 자
**원문**: "讓左者左昂右低"  
**설명**: 왼쪽 부분이 주가 되는 글자는 왼쪽을 높이고 오른쪽을 낮춰 균형을 맞춘다

**예시 글자**: 斷, 幣, 施

```
   ╱     (왼쪽이 높음)
  ╱╲    
 ╱  ╲   (오른쪽이 낮음)
```

---

### 4. 양우자(讓右者) - 오른쪽에 양보하는 자
**원문**: "讓右者右昂左低"  
**설명**: 오른쪽 부분이 주가 되는 글자는 오른쪽을 높이고 왼쪽을 낮춰 균형을 맞춘다

**예시 글자**: 騰, 輝

```
     ╲   (오른쪽이 높음)
    ╱╲  
   ╱  ╲ (왼쪽이 낮음)
```
