# 왕희지(王羲之) 서체 참고 자료

## 📁 폴더 구조

- `wangxizhi-images/` - 왕희지 집자성교서 한자 이미지 파일들
- `*.py` - 이미지 추출 및 메타데이터 생성 스크립트
- `wangxizhi-learning-guide.md` - 왕희지 서체 학습 가이드
- `wangxizhi-viewer.html` - 왕희지 서체 뷰어 HTML
- `*-metadata.json` - 한자별 메타데이터 (의미, 발음 등)

## 🎯 용도

한자 서예 학습을 위한 왕희지 집자성교서 참고 자료 모음입니다.
향후 한자 서예 코스 개발 시 활용될 예정입니다.
