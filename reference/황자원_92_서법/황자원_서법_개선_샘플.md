### 1. 천복자(天覆者) - 하늘이 덮는 자
**원문**: "天覆者凡畫皆冒於其下"  
**설명**: 위에 보개(宀)가 있는 글자는 나머지 획들이 모두 그 아래에 모여야 한다

**예시 글자**: 宇, 宙, 定

```
    宀    (보개두가 위를 덮음)
   ─┬─   
    │    (아래 획들이 보개 아래 집중)
    
실제 예시:
    宀     宀     宀
   ─宇─   ─宙─   ─定─
  (우)   (주)   (정)
```

---

### 2. 지재자(地載者) - 땅이 받치는 자
**원문**: "地載者有畫皆托於其上"  
**설명**: 아래에 받침이 있는 글자는 나머지 획들이 모두 그 위에 받쳐져야 한다

**예시 글자**: 至, 孟, 聖

```
   至孟聖  (위쪽 획들이 받쳐짐)
   ─┴─
  ━━━━━  (아래 받침이 전체를 떠받침)
  
실제 구조:
   ┌─至─┐
   └─────┘  (至자의 바닥이 넓게 받침)
   
   ┌─孟─┐
   └─────┘  (孟자의 기반이 안정)
```

---

### 3. 양좌자(讓左者) - 왼쪽에 양보하는 자
**원문**: "讓左者左昂右低"  
**설명**: 왼쪽 부분이 주가 되는 글자는 왼쪽을 높이고 오른쪽을 낮춰 균형을 맞춘다

**예시 글자**: 部, 幼, 即

```
부(部)자 구조:
  
  立 ╲     (왼쪽 '立'이 높고 주도적)
  │   ╲    
  │    阝   (오른쪽 '阝'가 낮고 보조적)
  
幼(幼)자 구조:
  
  幺 ╲     (왼쪽 '幺'가 위로 솟음)
   ╲  ╲    
    ╲  力  (오른쪽 '力'이 아래로 내려감)
```

---

### 4. 양우자(讓右者) - 오른쪽에 양보하는 자
**원문**: "讓右者右伸左縮"  
**설명**: 오른쪽 부분이 주가 되는 글자는 오른쪽을 길게 늘이고 왼쪽을 짧게 축소한다

**예시 글자**: 績, 議, 讀

```
績(績)자 구조:

糸 ←   → 責  (왼쪽 '糸'는 압축, 오른쪽 '責'은 확장)
│        ━━━  
│          責  (오른쪽이 더 넓은 공간 차지)

議(議)자 구조:

言 ←   → 義  (왼쪽 '言'은 좁게, 오른쪽 '義'는 펼침)
│        ╱ ╲  
│       ╱   ╲ (오른쪽 '義'가 확장하여 뻗어나감)
```

### 5. 분간자(分間者) - 사이를 나누는 자
**원문**: "分間者左右宜均"  
**설명**: 좌우로 나누어지는 글자는 좌우를 균등하게 배분해야 한다

**예시 글자**: 頗, 類, 明

```
明(明)자 구조:

日 │ 月   (중앙선을 기준으로 좌우 균등)
│  │  │   
日 │ 月   (일월이 같은 크기와 비중)

頗(頗)자 구조:

皮 │ 頁   (왼쪽 '皮'와 오른쪽 '頁'의 균형)
│  │  │   
├──┼──┤  (좌우 공간 배분이 동등)
```

---

### 6. 배향자(背向者) - 등지고 향하는 자
**원문**: "背向者撇捺宜均"  
**설명**: 삐침(撇)과 파임(捺)이 서로 등지는 형태의 글자는 양쪽의 기울기와 길이를 균등하게 해야 한다

**예시 글자**: 八, 人, 入, 文

```
八(八)자 구조:

  ╱ ╲     (왼쪽 삐침과 오른쪽 파임의 대칭)
 ╱   ╲    (각도와 길이가 균등)
╱     ╲   (아래로 갈수록 벌어짐)

人(人)자 구조:

  ╱╲      (사람이 서있는 모양)
 ╱  ╲     (두 다리의 균형)
╱    ╲    (안정적인 삼각형 구조)

文(文)자 구조:

  ╱ ╲     (위의 점과 삐침파임)
 ╱   ╲    
╱  ×  ╲   (중간에 교차하는 획)
```

---

### 7. 상전자(上展者) - 위로 펼치는 자
**원문**: "上展者上畫宜長"  
**설명**: 윗부분이 펼쳐지는 글자는 위쪽 가로획을 길게 하여 시각적 안정감을 준다

**예시 글자**: 奮, 奢, 壽

```
奮(奮)자 구조:

━━━━━━━━  (위쪽을 넓게 펼침)
    田      (중간은 적당한 크기)
  ┌────┐   
  │  大  │   (아래는 위를 받쳐줌)
  └────┘   

壽(壽)자 구조:

━━━━━━━━━  (위의 '士'부분을 넓게)
  ┌─────┐   
  │  口   │   (중간 부분들)
  │  ⽕   │   
  └─────┘   (아래는 상대적으로 좁게)
```

---

### 8. 하전자(下展者) - 아래로 펼치는 자  
**원문**: "下展者下畫宜長"  
**설명**: 아랫부분이 펼쳐지는 글자는 아래쪽 가로획을 길게 하여 안정적인 받침을 만든다

**예시 글자**: 畫, 禹, 豊

```
畫(畫)자 구조:

  ┌──┐      (위는 상대적으로 좁게)
  │田 │      
  │  │      
  └──┘      
━━━━━━━━━━  (아래 一자를 매우 길게)

禹(禹)자 구조:

    冂       (위는 간결하게)
    口       
    厶       
━━━━━━━━   (아래 기반을 넓게 확장)
```

### 2. ASCII 아트 설명 강화
**추가할 요소**:
- 실제 한자의 구조 표현
- 부수별 배치 설명  
- 획의 강약과 길이 표시
- 공간 배분 시각화

### 3. 체계적 시각화 패턴
```
기본 구조 → 실제 예시 → 변형 원리
   ┌─┐       實       ├─응용─┤
   └─┘    → 際例 →   │변화│
  이론적     구체적     │원리│
```
