# 황자원(黃自元) 간가결구 구십이법(間架結構九十二法)

## 개요
황자원의 간가결구 구십이법은 중국 서예에서 글자의 구조적 배치와 균형을 다루는 체계적인 이론입니다. 각 서법은 특정한 글자 구조의 원리를 제시하며, 서예 학습자들이 올바른 글자 형태를 익힐 수 있도록 돕습니다.

## 1-4번 서법: 기본 구조의 원리

![1-4번 서법](images/hwang_92/hwang_01-04.jpg)

### 1번: 天覆者凡畫皆冒於其下 (천복자범화개모어기하)
**원문:** 하늘이 덮는 자는 모든 획이 모두 그 아래에 가려진다
**설명:** 上面有覆盖笔画的字，下面所有部分都应当被覆盖在其下方，如宀头字等

```
天 (하늘 천)
┌─────┐
│  一  │  ← 상단 횡획이 전체를 덮음
│ 人   │  ← 모든 부분이 그 아래 위치
└─────┘

구조 분해:
   一
   ├── 하늘처럼 전체를 덮는 횡획
   大
   └── 모든 요소가 덮개 아래로

예시: 宇(집 우)
   宀
   ├── 지붕이 모든 것을 덮음
   于
   └── 아래 요소가 보호받음

핵심 원리: 상단의 덮개 역할을 하는 획 아래로 모든 요소가 들어가야 함
```

### 2번: 地載者有畫皆託於其上 (지재자유화개탁어기상)
**원문:** 땅이 받치는 자는 있는 획이 모두 그 위에 의탁한다
**설명:** 下面有承载笔画的字，上面所有部分都应当依托在其上方，如土底字等

```
王 (임금 왕)
│ 一 │  ← 상단 요소들
│ 一 │  
└───┘  ← 하단 횡획이 모든 것을 받침

구조 분해:
   一
   ├── 상단 횡획
   土 
   └── 땅처럼 받치는 하단 구조

예시: 至(이를 지)
   一
   ├── 위의 요소들이
   土
   └── 아래 받침 위에 안착

핵심 원리: 하단의 받침 역할을 하는 획 위에 모든 요소가 올라가야 함
```

### 3번: 讓左者右昂 (양좌자우앙)
**원문:** 왼쪽에 양보하는 자는 오른쪽이 높아진다
**설명:** 左边部分低让的字，右边部分应当高昂，形成呼应关系

```
作 (지을 작)
亻 │ 乍  ← 오른쪽 부분이 더 높이 위치
   │

구조 분해:
   亻
   ├── 왼쪽이 낮게 양보
   乍
   └── 오른쪽이 높게 상승

예시: 佳(아름다울 가)
   亻
   ├── 인변이 공간 양보
   圭
   └── 오른쪽이 위로 솟음
   
핵심 원리: 왼쪽 부분이 공간을 양보하면 오른쪽이 상승
```

### 4번: 讓右者左高 (양우자좌고)
**원문:** 오른쪽에 양보하는 자는 왼쪽이 높다
**설명:** 右边部分低让的字，左边部分应当高起，保持平衡

```
利 (이로울 리)
禾 │ 刂  ← 왼쪽 부분이 더 높이 위치
   │

구조 분해:
   禾
   ├── 왼쪽이 높게 솟음
   刂
   └── 오른쪽이 낮게 양보

예시: 和(화목할 화)
   禾
   ├── 왼쪽 곡식이 높이 자람
   口
   └── 오른쪽이 아래로 양보
   
핵심 원리: 오른쪽 부분이 공간을 양보하면 왼쪽이 상승
```

## 5-8번 서법: 길이와 폭의 조화

![5-8번 서법](images/hwang_92/hwang_05-08.jpg)

### 5번: 橫擔者中畫宜長 (횡담자중화의장)
**원문:** 가로로 담당하는 자는 중간 획이 마땅히 길어야 한다
**설명:** 有横担作用的字，中间的横画应当写得较长，起到承载作用

```
喜 (기쁠 희)
十 ← 상단
口 ← 중간 부분
┴─┴ ← 하단 횡획이 가장 길게

구조 분해:
   吉
   ├── 상단 부분
   一
   ├── 중간 횡획이 길게 연장
   口
   └── 하단을 안정적으로 지탱

예시: 書(글 서)
   聿
   ├── 상단 붓
   一
   ├── 중간 횡획이 전체를 관통
   日
   └── 하단 받침

핵심 원리: 여러 부분을 가로로 연결하는 중심 획의 연장
```

### 6번: 直筆者中豎宜正 (직필자중수의정)
**원문:** 직선 붓의 자는 중간 세로획이 마땅히 바르다
**설명:** 有中央竖画的字，该竖画应当写得端正垂直，作为字的主干

```
中 (가운데 중)
│
│ ← 중앙 세로획이 완전히 직선
│

구조 분해:
   口
   ├── 사각 틀
   │
   └── 중심을 관통하는 직선

예시: 申(펼 신)
   口
   ├── 외곽 틀
   │
   └── 중앙을 꿰뚫는 수직선

핵심 원리: 전체 글자의 중심축 역할을 하는 세로획의 정확성
```

### 7번: 勾拏法 (구나법)
**원문:** 갈고리로 끌어당기는 법
**설명:** 钩画要有力度，能够拉住整个字的结构，不可软弱无力

```
勾 (갈고리 구)
勹 ← 감싸는 형태의 구조
│ ○ ← 내부 요소를 감쌈
└─

구조 분해:
   勹
   ├── 갈고리로 감싸는 외곽
   ㄱ
   └── 안으로 끌어당기는 형태

예시: 句(구 구)
   勹
   ├── 감싸는 갈고리
   口
   └── 보호받는 내부

핵심 원리: 곡선적 포용과 직선적 지지의 결합
```

### 8번: 勾努法 (구노법)
**원문:** 갈고리로 힘을 주는 법
**설명:** 钩画要努力向上，体现出力量感和向上的精神

```
刀 (칼 도)
│ ← 직선적 힘
└─ ← 갈고리 형태의 마무리

구조 분해:
   丿
   ├── 날카로운 시작
   └┐
   └── 힘있는 갈고리 마무리

예시: 勺(국자 작)
   勹
   ├── 부드러운 곡선
   丶
   └── 힘있는 점으로 마무리

핵심 원리: 강직함과 유연함의 조화
```

## 9-12번 서법: 종횡의 균형

![9-12번 서법](images/hwang_92/hwang_09-12.jpg)

### 9번: 縱有行 (종유행)
**원문:** 세로에는 행렬이 있다
**설명:** 竖画之间要保持一定的行列关系，使字体纵向排列有序

```
樂 (즐거울 락)
白 ← 각 부분이 세로로 정렬
木 ← 중심축을 따라 배치

구조 분해:
   白
   ├── 상단 백 부분
   │  
   木
   └── 하단 목 부분이 수직 정렬

예시: 書(글 서)
   聿
   ├── 상단
   │
   日
   └── 하단이 수직선 상 정렬
   
핵심 원리: 세로 방향의 일관된 정렬과 균형
```

### 10번: 橫有列 (횡유열)
**원문:** 가로에는 열이 있다
**설명:** 横画之间要保持一定的列距关系，使字体横向排列整齐

```
무 (없을 무)
一 ← 가로선들이 수평 유지
一 ← 각 횡획의 평행 관계

구조 분해:
   一
   ├── 상단 횡선
   一
   ├── 중간 횡선
   一
   └── 하단 횡선 모두 평행

예시: 三(셋 삼)
   一
   ├── 짧은 횡선
   一
   ├── 중간 길이
   一
   └── 가장 긴 횡선
   
핵심 원리: 가로 방향의 수평적 질서 유지
```

### 11번: 勾斡法 (구알법)
**원문:** 갈고리로 돌리는 법
**설명:** 钩画要有旋转的势态，体现出动感和力度

```
建 (세울 건)
廴 ← 감싸면서 돌리는 형태
│

구조 분해:
   艷
   ├── 위에서 시작하여
   廴
   └── 갈고리로 돌아 감싸며 끝남

예시: 迯(달릴 진)
   辛
   ├── 내부 요소
   辶
   └── 회전하며 감싸는 형태
   
핵심 원리: 곡선적 움직임을 통한 역동성 표현
```

### 12번: 勾裹法 (구과법)
**원문:** 갈고리로 감싸는 법
**설명:** 钩画要能包裹内部笔画，形成包容感

```
包 (쌀 포)
勹 ← 완전히 감싸는 구조
○ ← 내부 요소를 보호

구조 분해:
   勹
   ├── 외부를 감싸는 틀
   巳
   └── 내부를 완전히 포용

예시: 匃(경단 홈)
   勹
   ├── 감싸는 외곽
   匕
   └── 보호받는 중심
   
핵심 원리: 포용적 구조를 통한 안정감 조성
```

## 13-16번 서법: 상하의 호응

![13-16번 서법](images/hwang_92/hwang_13-16.jpg)

### 13번: 上占地步寬 (상점지보관)
**원문:** 위가 차지하는 땅이 넓다
**설명:** 上部结构占据较大空间的字，下部应当收缩

```
宇 (집 우)
宀 ← 상단이 넓게 차지
于 ← 하단은 상대적으로 좁음

구조 분해:
   宀
   ├── 넓은 지붕이 전체를 덮음
   于
   └── 좀 더 좁은 공간에 안착

예시: 安(편안할 안)
   宀
   ├── 큰 지붕
   女
   └── 작은 하부
   
핵심 원리: 상하 비례에서 상단의 우세함
```

### 14번: 下佔地步寬 (하점지보관)
**원문:** 아래가 차지하는 땅이 넓다
**설명:** 下部结构占据较大空间的字，上部应当收缩

```
至 (이를 지)
一 ← 상단은 좁음
土 ← 하단이 넓게 차지

구조 분해:
   一
   ├── 짧은 상단
   土
   └── 넓게 퍼진 하단 받침

예시: 志(뜻 지)
   士
   ├── 작은 상부
   心
   └── 큰 하부
   
핵심 원리: 상하 비례에서 하단의 우세함
```

### 15번: 左佔地步寬 (좌점지보관)
**원문:** 왼쪽이 차지하는 땅이 넓다
**설명:** 左部结构占据较大空间的字，右部应当收缩

```
影 (그림자 영)
景 ← 왼쪽 부분이 넓음
彡 ← 오른쪽은 좁음

구조 분해:
   景
   ├── 넓은 왼쪽 경 부분
   彡
   └── 좁은 오른쪽 삼초변

예시: 歌(노래 가)
   可
   ├── 큰 왼쪽
   欠
   └── 작은 오른쪽
   
핵심 원리: 좌우 비례에서 좌측의 우세함
```

### 16번: 右佔地步寬 (우점지보관)
**원문:** 오른쪽이 차지하는 땅이 넓다
**설명:** 右部结构占据较大空间的字，左部应当收缩

```
郎 (사내 랑)
良 ← 왼쪽은 좁음
阝 ← 오른쪽이 넓게 차지

구조 분해:
   良
   ├── 좁은 왼쪽
   阝
   └── 넓은 오른쪽 이변

예시: 都(도시 도)
   者
   ├── 작은 왼쪽
   阝
   └── 큰 오른쪽
   
핵심 원리: 좌우 비례에서 우측의 우세함
```

## 17-20번 서법: 조밀과 개방

![17-20번 서법](images/hwang_92/hwang_17-20.jpg)

### 17번: 川升小異 (천승소이)
**원문:** 川자와 升자는 작은 차이가 있다
**설명:** 形似的字要注意细微差别，避免混淆

```
川 (내 천)     升 (오를 승)
│││           廾
│││           │

구조 분해:
川:           升:
 │││          ─┬─
 ├┼┤          ││
 평행선       교차점이 있음

예시: 州(고을 주) vs 巡(순찰 순)
   州: 세 개의 독립적 세로선
   巡: 연결된 획의 흐름
               
핵심 원리: 유사한 구조에서도 세밀한 차이점 구별
```

### 18번: 己已小異 (기이소이)
**원문:** 己자와 已자는 작은 차이가 있다
**설명:** 相似字形的细微差别决定不同含义，须仔细区分

```
己 (몸 기)     已 (이미 이)
己             已

구조 분해:
己:           已:
 ┌─┐          ┌─┐
 │ └──       │ │
 └───        └─┴
 열린 구조    닫힌 구조

예시: 巳(뱀 사)
   己과 已의 중간 형태
   각각 미세한 차이로 구분
               
핵심 원리: 미세한 형태 변화가 만드는 의미 차이
```

### 19번: 修短合度 (수단합도)
**원문:** 길고 짧음이 법도에 합당하다
**설명:** 笔画的长短要符合字体结构的需要，保持适当比例

```
修 (닦을 수)
亻 ← 짧은 부분
修 ← 긴 부분이 조화

구조 분해:
   亻
   ├── 짧고 간결한 인변
   攸
   └── 길고 복잡한 오른쪽

예시: 短(짧을 단)
   矢
   ├── 짧은 화살
   豆
   └── 적절한 길이의 콩
   
핵심 원리: 각 부분의 길이가 전체와 조화를 이룸
```

### 20번: 燥潤合度 (조윤합도)
**원문:** 마르고 윤택함이 법도에 합당하다
**설명:** 笔画的枯润要适度，既不过于干枯也不过于湿润

```
燥 (마를 조)   潤 (윤택할 윤)
火 + 燥       氵+ 閏

구조 분해:
燥:           潤:
 火            氵
 ├── 불(마름)  ├── 물(촉촉함)
 躁           閏
 └── 발건     └── 엔달

예시: 건조한 성질과 촉촉한 성질의 조화
               
핵심 원리: 상반된 성질의 요소들이 균형을 이룸
```

## 21-24번 서법: 자세와 기세

![21-24번 서법](images/hwang_92/hwang_21-24.jpg)

### 21번: 向背法 (향배법)
**원문:** 향하고 등지는 법
**설명:** 字的各部分要有向背关系，形成呼应和对比

```
聰 (총명할 총)
耳 ← 귀 부분이 앞을 향함
聰 ← 전체적인 방향성

구조 분해:
   耳
   ├── 왼쪽 귀(앞향)
   總
   └── 오른쪽 총(뒤향)

예시: 背(등 배)
   北
   ├── 서로 등지는 부분
   月
   └── 아래쪽 달 부분
   
핵심 원리: 글자 구성 요소들의 방향성과 조화
```

### 22번: 偏正法 (편정법)
**원문:** 기울고 바른 법
**설명:** 偏旁和正体要相互配合，斜正相得益彰

```
政 (정치 정)
```

### 91번: 出神入化 (출신입화)
