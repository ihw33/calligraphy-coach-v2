## 활용 방법

### 학습자용 평가 방법
1. **기초 단계 (1-20번)**: 기본 구조와 균형감 위주로 평가
2. **중급 단계 (21-60번)**: 세부 기법과 조화 원리 적용 평가  
3. **고급 단계 (61-80번)**: 정신적 깊이와 예술적 완성도 평가
4. **최고 단계 (81-92번)**: 궁극적 경지와 예술적 성취 평가

### 평가 기준
- □ 체크박스: 각 항목별로 달성 여부 확인
- 각 서법당 4개 평가 포인트로 구성
- 단계별 난이도 조절 가능
- 구체적이고 실용적인 평가 기준 제시

### 점수 환산
- 각 체크박스당 25점 (총 100점 만점)
- 70점 이상: 해당 서법 기준 달성
- 단계별 평균 점수로 전체 수준 파악
