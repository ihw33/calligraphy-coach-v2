# 한자능력검정시험 1급 Page 39

## 한자 목록

### 1. 袈 (가) - 가사
- **부수**: 衣 (옷 의)
- **획수**: 5획
- **의미**: 가사(袈裟)
- **설명**: Kasaya의 音譯字로, 장삼 위에 왼쪽 어깨에서 오른쪽 겨드랑이 밑으로 걸쳐(加) 입는 중의 (衣), '가사(袈裟)'를 뜻한다.
- **단어**: 錦袈(금가)

### 2. 苛 (가) - 가혹할 가
- **부수**: 艸 (풀 초)
- **획수**: 5획
- **의미**: 가혹할 가
- **유의자**: 虐, 酷
- **설명**: 원래 자잘한 (卄·)을 뜻했으며, 파쟁하여 사람이 잘고 까다로운 것, '가혹하다, 까다롭다'는 뜻이다.
- **단어**: 苛刻(가각), 苛求(가구), 苛禮(가례), 苛法(가법), 苛稅(가세), 苛殃(가앙), 苛政(가정), 苛疾(가질), 苛虐(가학), 苛酷(가혹), 細苛(세가), 小苛(소가), 嚴苛(엄가), 暴苛(폭가)

### 3. 呵 (가) - 꾸짖을 가
- **부수**: 口 (입 구)
- **획수**: 5획
- **의미**: 꾸짖을 가
- **유의자**: 喝, 譴, 斥, 叱, 責
- **설명**: 소리(口)를 입 밖으로 내는(丁) 것으로, '꾸짖다, 웃다'는 뜻
- **단어**: 呵呵(가가), 呵喝(가갈), 呵怒(가노), 呵凍(가동), 呵止(가치), 呵叱(가질), 呵責(가책), 呵許(가허), 呵護(가호), 受呵(수가), 笑呵(소가), 前呵(전가), 叱呵(질가), 筆呵(필가)

### 4. 駕 (가) - 멍에 가
- **부수**: 馬 (말 마)
- **획수**: 5획
- **의미**: 멍에 가
- **유의자**: 御
- **설명**: 수레를 (馬)에 붙(加)이는 데서, '멍에, 멍에를 메우다' (말을) 부리다'는 뜻
- **단어**: 沈駕(가륙), 駕辭(가사), 駕御(가어), 車駕(거가), 仙駕(선가), 晩駕(만가), 小駕(소가), 從駕(종가), 駐駕(주가)

### 5. 哥 (가) - (姓) 가
- **부수**: 口 (입 구)
- **획수**: 7획
- **의미**: (姓) 가
- **설명**: 입김이 퍼지는(可) 것으로, 본래 '노래(歌)'를 뜻하나 국어에서는 金哥, 李哥에서 보듯 주로 '(姓)'을 뜻한다.
- **단어**: 哥哥(가가), 金哥(김가), 李哥(이가), 二哥(이가), 大哥(대가), 八哥(팔가)

### 6. 嫁 (가) - 시집갈 가

- **의미**: 시집갈 가

- **설명**: 계집(女)이 친가를 떠나 남편의 (家)으로 가는 데서, '시집가다'는 뜻이다.

### 7. 稼 (가) - 심을 가
- **부수**: 禾 (벼 화)
